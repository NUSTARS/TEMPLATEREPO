# Template Repository
On GitHub, navigate to the main page of this repo. Then, above the file list on the top right click **Use this template**. 

Select **Create a new repository**. Then select the correct owner (probably NUSTARS) and give it a proper name and description. 

Use the README.md file to actually give a description as to what your project wants to accomplish, and what it contains.

Additionally, navigate from settings -> rulesets -> new rulesets and import in the .json file in the repo (requires PRs)
